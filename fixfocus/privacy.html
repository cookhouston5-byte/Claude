Privacy policy

Last updated November 24, 2026

FixFocus helps you find repair and how-to videos. It is run by Houston. Google and YouTube do not make it. There is no sign-in and no user account.

What you search for

The words you type are sent to FixFocus's own server. The server asks YouTube for matching videos, keeps the ones that look like repairs or how-tos, and sends those results back to your browser. YouTube receives the search words. The YouTube key used for that request stays on the server. It is not sent to your browser.

What stays in this browser

Recent searches, and the videos you mark with "I fixed it", are saved in this browser only. Clear history and fixes, in the menu, removes them. Clearing this site's data in your browser removes them too.

What the server remembers

YouTube gives the site a free daily limit. To stay inside it, the server keeps two things in its memory:

  • the results of recent identical searches, for about a day, so it does not ask YouTube again
  • a count of searches from each network address, so one visitor cannot use up the shared limit

There is no database of visitors. That memory is wiped when the server restarts or goes to sleep, which the free host does after a quiet period. FixFocus does not sell information. It does not use ads, analytics, or tracking cookies.

Watching a video

Videos play in YouTube's player on this page. YouTube's privacy policy applies to playback.

Hosting

The site is hosted on Render. Render may keep ordinary connection logs in order to run the service. FixFocus does not use those logs for advertising.

Changes

If this policy changes, the date at the top will change and the new version will be on this page.

Contact

This site does not ask for your email. If a contact address is added later, it will be listed on this page.
